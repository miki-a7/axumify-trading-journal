# Axumify - Private Personal Trading Journal

A comprehensive, secure trading journal application built with modern web technologies.

## Tech Stack

- **Frontend:** Next.js 14 + React 18 + TypeScript
- **Styling:** Tailwind CSS
- **Database:** Supabase (PostgreSQL)
- **ORM:** Prisma
- **Auth:** NextAuth.js
- **Deployment:** Vercel

## Features

- Trade journaling and tracking
- Performance analytics
- Calendar view
- Backtesting tools
- Goal tracking
- Prop trader tools
- Customizable checklists

## Getting Started

```bash
npm install
npm run dev
```

## Environment Setup

See `.env.example` for required environment variables.
